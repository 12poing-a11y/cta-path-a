## 3. 过滤规则（固定）

两个过滤都在**T 日收盘后**对候选（`path_a_candidate` 状态 `ok`）判定，通过的候选 T+1 成交；被过滤的候选**不进入候选列表**（因此也不占板块/名额）。只用 T 日及以前的数据。不影响 `lots0` 信号（它们本来就不入场）。

- **F1 `--filter-unit-risk`**
  - 名义半条：`1 手名义 = close_T × mult` **严格大于** `0.5 × 名义帽额度`时不入场。**名义帽额度 = T 日用于定手数的权益 `sizing_eq` × `max_gross_pct`/100**（账户级总帽，**不扣已持仓名义**；扣已持仓的"剩余额度"会与 `apply_portfolio_caps` 已有的缩放重复，也让过滤依赖持仓路径，故不采用。这是对"当时名义帽额度"的解读，写在这里，结果之后不改）。
  - 风险半条：`risk_per_lot > day_risk` 时不入场。第 0b 步已证明这条在 `min_lots=0` 下恒被 `floor` 挡掉（980 个可入场候选日 0 个触发，125 个 0 手日全部是风险买不起），**按磊的规定 F1 只保留名义半条**；代码里风险半条的实现仍写入并有测试，但本轮不启用。
- **F2 `--filter-atr-spike`**
  - `ATR14_T / ATR100_T` **严格大于 1.5** 时不入场。ATR14 = 引擎自己用的 R6c 调整序列 `AdjustedSeries.atr14`；ATR100 = 同口径的 100 日平均真实波幅（同合约 TR，换月日用新合约自己的前收；`AdjustedSeries.atr_n(i, 100)`，新增方法，`atr_n(i,14)` 必须等于 `atr14(i)`，有测试）。
  - **ATR100 不可得（`T` 之前不足 100 根有效 TR）时不触发过滤**（只能放行，不能猜）。窗口起点前只有 60 根 warmup，所以**窗口前 40 个交易日 F2 不起作用**；结果里报告这段天数和因此放行的候选数。
- 比较都用严格大于，阈值 50% 与 1.5 固定，不扫。

## 4. 指标定义（全部取自各组 `--out` 的结果 JSON 或同快照离线重放，Base 成本为主、Stress 并列）

沿用上一轮已用的口径，不改：
- **净收益** `ret_pct`；Stress 取 `cost_scenario_contrast.rows.stress`（每组都跑）。**最大回撤** 同。
- **单笔实际风险**（占权益%）= `|entry − stop| × lots × mult ÷ 入场前一交易日收盘权益`，对全部已平仓交易，报中位数与最大值。
- **最高名义占用** = 权益曲线 `gross_pct` 最大值（盯市）；并列报入场时 `caps_entry_gross_max`。
- **实际持仓数分布** = 权益曲线每天 `held`（日末持仓数）的天数分布（0/1/2/3）。
- **跳过信号**（单位：信号日，同一信号连续几天每天算一次），按 §0c 的流水线顺序分四类 + 其余：**算出 0 手** / **名义帽缩到 0** / **持仓数已满**（含当日 N 帽挡掉和满仓日）/ **板块已满**；另列：ATR 风险帽缩到 0、硬裁剪、帽内动量；以及过滤器拦下的信号日（F1/F2 分别计）。用 `archive/R8/_static_sizing.py` 同一套归类逻辑，在同一冻结快照上做离线重放（与 live 逐位一致才使用）。
- **PSR**：Base 日收益对 0 基准。**DSR**：`deflated_sharpe_ratio(Base 日收益, n_trials=18, mean_abs_corr=0.0)`（另报 n=21 的读法），**只如实报告，不作通过条件**。
- **PBO（每组）**：CSCV，S=8，70 组合；矩阵 = `lab/research/validation/pbo_path_a_matrix.json` 的 11 个参数试验列 + 该组 Base 日收益列（T=215，K=12）。另报全族 PBO（参考，不作通过条件）。
- **走步**：`walk_forward_segments(Base 日收益, n_folds=5)`，数 Sharpe > 0 的折数；另列每折 Sharpe **相对 `E1000k`（R8b 对照）是变好还是变差**（只报告，不设阈值）。
- **被过滤掉的交易（R8b 的 F1 / F2 / F1F2 各自）**：
  - 主口径 = **对照组 `E1000k` 的已平仓交易中，其入场候选（信号日 = 入场日的上一交易日）在该组过滤规则下会被拦下的那些**（在对照组自己的路径上判定，不受路径变化影响）。
  - 前半年 / 后半年：以对照组权益曲线日期序列（216 天）对半分，前 108 天为前半，入场日属于哪一半就归哪一半。
  - 每半年报**笔数**和**合计盈亏** = Σ 价格盈亏（元）= 方向 ×（出场−入场）× 手数 × 合约乘数（多 = +1，空 = −1；`closed_pnls` 无单笔成本字段，成本不分摊），并列报 Σ R。
  - 另报路径口径（仅供参考）：对照组有而该组没有（按 品种+入场日 匹配）的交易的同口径盈亏，以及该组新出现的交易。

## 6. R8b 通过标准（只用于 R8b 的 F1 / F2 / F1F2；全部满足才算通过）

1. Base 净收益 > 0 且 > `E1000k` 的 Base；Stress 净收益 > 0 且 > `E1000k` 的 Stress。
2. Base 与 Stress 最大回撤都 ≤ 10%。
3. 单笔实际风险最大值 ≤ 3% 权益（Base 成本，全部已平仓交易）。
4. 该组 PBO（S=8，K=12）≤ 0.5。
5. 走步 5 折中至少 3 折 Sharpe > 0。
6. **被过滤掉的交易（上面的主口径）在前半年和后半年的合计盈亏都严格 < 0**；任一半年没有被过滤的交易（合计 = 0）、或合计 ≥ 0，均判不通过（只在某半年有效的判不通过）。
7. 对满足 1–6 的组做 `scripts/audit_exit_vs_daily.py --fail-on-mismatch`：有不符 → 该组判未通过（审计失败）。
- DSR（n_trials = 18，另报 21）只报告，不设阈值。
- **任一组运行失败按失败如实报告，不静默重跑换结果**（环境性失败可重跑，须在 `progress.md` 记录）。
