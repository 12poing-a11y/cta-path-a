## 采纳（Keep / Do）

| 项 | 决策 | 说明 |
|----|------|------|

| 验收门槛 | **采纳** | 未来函数、复现、账本勾稽、覆盖率、成本情景 |

## 明确不做 / 暂缓（Defer）

| 项 | 原因 |
|----|------|
| 再加 ADX / 布林带宽 / ATR% 作正式开仓条件 | 过滤器堆砌 → 回测变美、信号变少；与现有旁路重叠 |
| 放宽正式入场门槛 | 正式仍暂停；先查亏损与口径污染 |
| 观察袖套并入 `paper_book` | 保持 Shadow |
| Transformer / RL / 重型 ML | P3 以后 |
| 换重量级回测平台 | 成本高、打断现有 Actions/Notion |
| 多时段盘中 brief 合入本仓 | 已交 grokbot 观察，有效再议 |
| 一次把 P0–P3 全做完 | 维护成本高于收益 |

## 分期（唯一路线图）

### P0 — 研究可信度（立刻做）

1. **混价锁死**：同一笔持仓 entry / stop / mark / exit **同一价格基础**；禁止合约开 + 连续止盈止损 — **已做**（`manage_ohlc_bar`）  
2. **主力合约选择**：calendar nearest ≠ OI 主力；超差（默认 3%）强制 proxy — **已做**（`basis_rejected`）；OI 映射仍待后续  
3. **proxy 进主 KPI**：`proxy_entry_share` / `same_day_exit_n` — **已做**  
4. **paper_book**：同日双跑幂等、入场日不吃盘前 15m、原子写、拒绝回退 asof — **已做**；组合帽/next_open 对齐仍待  
5. **日报陈旧熔断**：`bar_date` 对齐期望会话；静默降级改显式 — 待做  
6. **Gate 接线**：scorecard 读产物布尔；登记每次正式回测/扫参 — 待做  

**正式晋升已完成**（2026-11-15）：`historical_backtest_latest.json` + `formal_scorecard_latest.json`  
同窗结果：**−7.6%/DD20.5 → +5.0%/DD3.3**（成交 43；结论「继续L1」；PBO≈0.39）。旧污染成绩已归档于 `archive/scorecard/`。  

### P1 — 搞清盈亏从哪来

1. 完整收益归因（品种/板块/多空/持仓天数/退出原因/席位/换月/成本）  
2. Regime 影子标签 + 策略×状态矩阵（统一成交与成本口径）  
3. 组合相关性 / 因子集中度影子（不替代现有 Top3/板块帽）

- Gamma × 期货行为联合  
- 跨品种验证  

### P3 — 效率层

## 与多方审计的对齐说明

审计主线（系统可信度 > 策略赚钱）**全盘采纳**。  
分歧处本仓裁决：

1. **ADX Regime**：采纳「四态引擎」概念，但 **只做影子+归因**，不进正式开仓。  
2. **立刻改代码**：审计原文偏「先清单后改」；本仓在清单落地后 **立即修 P0-blocker**（账本双跑、混价），因它们已污染正在用的纸面与 KPI 解读。  
3. **影子品类胜率**：保留；在 P0 混价修好前，解读时标注「连续口径、非正式成绩」。
